## What counts as an Asset

"Assets" means all artwork and media created for Craftaria, wherever it sits
in this repository, including:

- images, sprites, sprite sheets, tilesets, animations and textures;
- Aseprite and other source art files;
- music, sound effects and other audio;
- fonts, logos and icons made for Craftaria;
- every file in an `assets/` directory, except source code files.

Map data, the map format, protocol definitions and source code are not
Assets; they are covered by [LICENSE](LICENSE).
